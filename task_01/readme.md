# Task 1 - Personal Portfolio Website

## 1. Aim
To design and develop a simple Personal Portfolio Website
using HTML and CSS.

## 2. Project Description
A Personal Portfolio Website is used to display basic
information about a student.

It contains personal details, educational information,
skills and contact details.

## 3. Technologies Used
- HTML
- CSS

## 4. Files Included
- index.html
- style.css
- README.md

## 5. Objectives
- To create a personal portfolio webpage.
- To display educational details.
- To list personal skills.
- To provide contact information.
- To learn basic HTML and CSS concepts.

## 6. HTML Concepts Used
- HTML headings
- Paragraphs
- Links
- Lists
- Sections
- Header and footer

## 7. CSS Concepts Used
- Background color
- Text color
- Border
- Border-left
- Border-bottom
- Padding
- Margin
- Text alignment

## 8. Website Sections
1. About Me
2. Education
3. My Skills
4. Contact Me

## 9. How to Run the Project
1. Download all project files.
2. Keep index.html and style.css in the same folder.
3. Open index.html in a web browser.
4. The Personal Portfolio Website will be displayed.

## 10. Conclusion
This project helped me understand how HTML is used
to create webpage structures and how CSS is used
to design attractive webpages.
