# Task 3 - Online Learning Platform

## 1. Aim
To design and develop a simple Online Learning Platform
using HTML and CSS.

## 2. Project Description
An Online Learning Platform is a website that provides
learning information and course details to students.

It helps students explore different courses and improve
their knowledge through online learning.

## 3. Technologies Used
- HTML
- CSS

## 4. Files Included
- index.html
- style.css
- README.md

## 5. Objectives
- To create an online learning webpage.
- To display available courses.
- To provide information about the platform.
- To display contact details.
- To understand basic HTML and CSS concepts.

## 6. HTML Concepts Used
- HTML headings
- Paragraphs
- Links
- Sections
- Div elements
- Header and footer

## 7. CSS Concepts Used
- Background color
- Text color
- Border
- Border-left
- Border-bottom
- Padding
- Margin
- Text alignment
- Hover effect

## 8. Website Sections
1. Home
2. Available Courses
3. About Us
4. Contact Us

## 9. How to Run the Project
1. Download all project files.
2. Keep index.html and style.css in the same folder.
3. Open index.html in a web browser.
4. The Online Learning Platform webpage will be displayed.

## 10. Conclusion
This project helped me understand how to create an
Online Learning Platform webpage using HTML and CSS.
It improved my knowledge of webpage structure and
styling concepts.
