# Task 2 - College Information and Admissions Website

## 1. Aim
To design and develop a College Information and Admissions
Website using HTML and CSS.

## 2. Project Description
This website provides information about a college,
available courses, admission details and contact information.

It helps students understand the college and its facilities.

## 3. Technologies Used
- HTML
- CSS

## 4. Files Included
- index.html
- style.css
- README.md

## 5. Objectives
- To create a college information webpage.
- To display college details.
- To list available courses.
- To provide admission information.
- To display contact details.

## 6. HTML Concepts Used
- HTML headings
- Paragraphs
- Links
- Lists
- Sections
- Header and footer
- Button

## 7. CSS Concepts Used
- Background color
- Text color
- Border
- Border-left
- Border-bottom
- Padding
- Margin
- Text alignment
- Hover effect

## 8. Website Sections
1. Home
2. About Our College
3. Our Courses
4. Admissions
5. Contact Us

## 9. How to Run the Project
1. Download all project files.
2. Keep index.html and style.css in the same folder.
3. Open index.html in a web browser.
4. The College Information Website will be displayed.

## 10. Conclusion
This project helped me understand how to create a
college information webpage using HTML and CSS.
It also improved my knowledge of webpage styling
and design.
